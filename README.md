# ReggiDev ESLint config

## Setup

Install dependencies:
```
npm i -D eslint @reggidev/eslint-config
```

### React

Inside `eslint.config.mjs`
```
import config from '@reggidev/eslint-config/react.mjs'

export default config
```

### Node.js

Inside `eslint.config.mjs`
```
import config from '@reggidev/eslint-config/node.mjs'

export default config
```
